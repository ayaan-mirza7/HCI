# Ayaan Mirza | Personal Portfolio

An interactive, single-page personal profile that presents my academic background, experience, projects, skills and achievements. It is built with plain HTML, CSS and JavaScript, so it needs no build step or dependencies.

## Aim of Work

To design and develop an interactive personal profile that effectively presents professional, academic, social, blogging, project, and other activities while applying established principles of Human-Computer Interaction and evaluating the usability of the resulting interface.

## Features

- **Single-page layout** with a sticky navigation bar that highlights the current section while scrolling
- **Sections:** Home, About & Education, Experience, Projects, Skills, Achievements, Contact
- **Light and dark theme** toggle that follows the system preference and remembers the visitor's choice
- **Contact form** that opens the visitor's email app with a pre-filled message
- **Responsive design** for phones, tablets and desktops
- **Scroll animations** that respect the reduced-motion setting

## HCI Principles Applied

| Principle | How it is applied |
|---|---|
| Visibility of system status | The navigation highlights the active section |
| Consistency and standards | Repeated card layout, consistent spacing, colours and typography |
| Recognition over recall | Persistent top navigation with clear labels |
| Flexibility and efficiency of use | Skip-to-content link, anchor navigation, theme toggle |
| Aesthetic and minimalist design | Clean layout with focused content in every section |
| Accessibility | Semantic HTML, visible keyboard focus, readable contrast in both themes, labelled form fields, reduced-motion support |
| Error prevention | Required form fields and email validation |

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox)
- Vanilla JavaScript (IntersectionObserver, localStorage)

## Deployment

The site is static and can be hosted for free.

**GitHub Pages**
1. Create a public repository named `ayaan-mirza7.github.io`.
2. Upload `index.html` and `README.md`.
3. Go to Settings → Pages and select the `main` branch as the source.
4. The site will be live at `https://ayaan-mirza7.github.io`.

**Netlify or Vercel**
1. Push the files to a GitHub repository.
2. Import the repository on the hosting platform.
3. Leave the build command empty and deploy.

## Usability Evaluation

Usability can be evaluated by:

1. Asking 5–10 users to complete tasks such as finding the projects, locating the contact details and switching the theme.
2. Recording task success rate and time taken.
3. Collecting the System Usability Scale (SUS) questionnaire.
4. Reviewing the interface against Nielsen's 10 usability heuristics.

Results can be added to this section once testing is complete.
